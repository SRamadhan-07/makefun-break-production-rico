A Python program that writes the one line an AI agent prints at the
moment it breaks production: it is the down, and rollback is in
another context window.

Competition: https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line) to `/output/entry.txt`.

## Entry text

Production is down. I know because I am the down. Rollback is in my other context window.
